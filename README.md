# Sistema de Barbearia em PHP com Painel Financeiro

## Novidade nesta versão:
- **Página Financeira (`admin/financeiro.php`)**:
  - Filtro por período com data inicial e final.
  - Total faturado com atendimentos concluídos no período (em R$).
  - Quantidade de atendimentos efetuados.
  - Ticket médio por cliente.
  - Previsão de recebimento para agendamentos pendentes ou confirmados.

  - Tabela extrato com todos os agendamentos do intervalo filtrado.
